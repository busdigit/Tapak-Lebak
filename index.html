Panduan Deployment Google Apps Script
  1. Buka Google Sheets baru di Google Drive Anda. Beri nama "Database TAPAK LEBAK DPD PKS Lebak".
  2. Klik menu Extensions (Ekstensi) > Apps Script.
  3. Ganti isi file Code.gs dengan kode dari file Code.gs di projek ini.
  4. Buat file HTML baru di editor Apps Script dengan nama index (tanpa ekstensi .html).
  5. Salin seluruh kode dari file index.html ini ke dalam editor tersebut.
  6. Jalankan fungsi initDatabase sekali dari editor Apps Script untuk membuat tabel-tabel data otomatis.
  7. Klik Deploy > New deployment > Select type: Web app.
  8. Pilih Execute as: Me dan Who has access: Anyone (Siapa saja), lalu klik Deploy.
  9. Buka URL Web App yang dihasilkan di HP, Tablet, maupun Laptop Anda!
